# VARBAN MARKETS — WEB APP TRANSLATION SKILL

## OBJECTIVE
Implement complete, production-quality internationalization (i18n) across the existing web application. Support exactly these five language options:
- English (default) - `en`
- French - `fr`
- Spanish - `es`
- Portuguese - `pt`
- Simplified Chinese - `zh-CN`

## CORE RULES
1. **Inspect Before Changing**: Reuse existing `i18n-context` and `i18n-dictionary`.
2. **Translate the Whole App**: Cover every route, modal, dialog, table, and disclaimer.
3. **Preserve Behavior and Design**: No layout shifts or feature removal.
4. **Native-Quality Language**: Professional financial terminology.
5. **No Mixed-Language UI**: Ensure zero hardcoded English remains in target locales.
6. **Accessibility**: Set `lang` attribute and maintain keyboard navigation.
